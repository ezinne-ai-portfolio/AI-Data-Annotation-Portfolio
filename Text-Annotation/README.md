# Text Annotation Portfolio

## Project Overview

This project demonstrates practical experience in text annotation using Label Studio.

The exercise involved annotating 15 customer-support messages to practise classifying customer feedback and identifying the purpose and nature of each message.

## Annotation Tasks Completed

### 1. Sentiment Classification
Identified the emotional tone expressed in each customer message.

Categories practised included:
- Positive
- Negative
- Neutral

### 2. Intent Classification
Identified what each customer was trying to communicate or achieve.

### 3. Issue Classification
Categorised customer messages according to the issue or problem being reported.

## Tools Used

- Label Studio
- JSON annotation export

## Practical Workflow

1. Reviewed each customer-support message.
2. Identified its sentiment.
3. Determined the customer's intent.
4. Classified the reported issue.
5. Applied the appropriate labels in Label Studio.
6. Exported the completed annotations in JSON format.
